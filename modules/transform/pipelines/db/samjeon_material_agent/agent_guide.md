# 송파삼전점 일별 집계 CSV 해석 가이드

`CEO_DB/송파삼전점_직영점/YYYY_MM/YYYY_MM.csv`는 날짜당 한 행이다. 질문에 필요한 월과 날짜만 읽는다. 이 폴더에는 상세 거래, 품목, 검수, 파일 검증 자료가 게시되지 않는다.

원천별 질문은 `CEO_DB/매출종합/`, `CEO_DB/주문서종합/`, `CEO_DB/물류종합/`에서 해당 월 CSV만 읽는다. 세 폴더 모두 현재는 송파삼전점 기준이다. 주문서는 푸드가이드, 물류는 물류담 원천이다. `원천상태`와 `확인필요`를 먼저 확인한다.

## 수치

- `관측매출원`은 송파삼전점 전체 원천 매출이며 `홀매출원`은 그중 OKPOS 소계다. 차액을 자동으로 배달 매출이라고 부르지 않는다.
- `관측원재료포장재매입원`은 원재료와 포장재의 매입 관측액이다. 재고 사용원가나 확정 손익이 아니다. `직원식대원`, `기타매입원`, `미분류매입원`은 별도 금액이다.
- 날짜 범위를 합산할 때 금액 열은 더하되 비율 열은 더하거나 평균하지 않는다. 기간 매입률은 기간 매입액을 기간 매출액으로 나눠 다시 계산한다.

## 자료 상태

- `자료상태`, 원천별 상태, `확인필요`, `상태사유`를 먼저 확인한다. `잠정`·`누락`·`오래됨`은 확정 자료가 아니다.
- 구매액 0원은 관측 행이 없다는 뜻일 수 있다. 수집·마감 근거 없이 확정 무거래라고 말하지 않는다.
- 확정 매입률은 매출·매입 마감이 완료되고 미분류 행이 없을 때만 사용한다. 그 외 잠정 비율은 잠정이라고 밝히고, 누락·오래됨에는 판단을 보류한다.
- 파일은 UTF-8 BOM이며 월별로 누적 갱신된다. 질문의 기준일이 파일의 마지막 날짜보다 늦으면 자료가 없다고 알린다.

## 답변 범위

일별·월별·지정 기간의 집계와 자료 상태만 이 CSV의 근거로 답한다. 품목별 구매, 개별 거래 원인, 원행 근거, 상세 PDF, 월말 전망은 이 게시본에서 제공하지 않는다. 추측으로 채우지 말고 필요한 원천을 알려준다.
