# 닭사용량수기입력컬럼추가

## Task

`fin_product_map_review_input.csv`(상품 검수 파일)에 닭 사용량을 사람이 엑셀로 직접 입력할 수기 전용 컬럼 3개(`닭유형_manual`, `사이즈_manual`, `닭사용량_manual`)를 추가한다.

이 파일은 사람이 편집하는 동시에 DAG가 매 실행마다 통째로 재생성하는 파일이다. `write_review_map()`이 `reindex(columns=REVIEW_COLUMNS)`로 스키마를 강제하므로, 컬럼만 추가하면 다음 DAG 실행에서 수기 입력값이 경고 없이 소실된다. **따라서 스키마 상수 변경 + 재생성 시 수기값 보존 merge가 한 세트로 들어가야 한다.**

또한 LLM 분류 루프가 이 컬럼을 절대 건드리지 않도록 격리해야 한다.

## 컬럼 스펙

| 컬럼 | 허용값 | 설명 |
|---|---|---|
| `닭유형_manual` | `뼈닭` / `순살` / 빈칸 | 빈칸 = 닭 미사용 |
| `사이즈_manual` | `소` / `중` / `대` / `1인` / `2인` / 빈칸 | |
| `닭사용량_manual` | 숫자(소수점) / 빈칸 | 주문 1개당 닭 마리수 |

입력 위치 규칙 (AGENTS.md에 문서화):
- 사이즈가 **옵션 행**으로 분리된 메뉴 → 옵션 행에 입력, 메인 행은 빈칸
- 사이즈가 **메뉴명에 고정**된 메뉴(`1인 순살 닭도리탕(밥포함)`, `2인 순살 반반`) → 메인/1인 행에 입력
- 닭 미사용 행(리뷰·음료·주류·토핑 등) → 3컬럼 모두 빈칸 유지

`REVIEW_COLUMNS` 마지막(`"검수사유"` 뒤)에 `*MANUAL_CHICKEN_COLUMNS`를 붙인다.
`REVIEW_INTERNAL_COLUMNS`는 `REVIEW_COLUMNS` 파생 리스트라 자동 반영된다.

**`MAP_COLUMNS`에는 절대 추가하지 않는다.** 이것이 LLM 격리의 핵심 — `map_df`에 컬럼이 존재하지 않으면 LLM 경로가 물리적으로 접근할 수 없다.

`판매구분`(배달/홀)은 행의 `source`로 이미 결정된다(`posfeed`/`배민수동`/`쿠팡수동`=배달, `okpos`=홀). 현재 환산표에서 배달·홀 순살 값이 동일하므로 **판매구분 축은 `CHICKEN_USAGE_TABLE`에 넣지 않는다.**

### 2. `load_review_map()` (line 395) — 정규화만 추가

기존 파일에 컬럼이 없어도 `df.reindex(columns=REVIEW_INTERNAL_COLUMNS, fill_value="")`(line 402)가 빈칸으로 채우므로 **별도 마이그레이션 스크립트 불필요**. `reindex` 직후 수기 3컬럼에 `.fillna("").astype(str).str.strip()`만 적용한다.

### 3. `write_review_map()` (line 428) — 보존 merge

`review_df`는 `build_review_rows(map_df)` 산출물이라 수기 컬럼이 **항상 비어 있다**. 저장 직전 디스크의 기존 파일에서 수기값을 읽어 되살린다.

`output_df = review_df.reindex(...)` 직후, `_mark_duplicate_labels()` 호출 전에 삽입:

```python
def _restore_manual_chicken_columns(output_df: pd.DataFrame) -> pd.DataFrame:
    """DAG 재생성 시 사람이 엑셀로 입력한 닭 사용량 컬럼을 디스크에서 되살린다."""
    result = output_df.copy()
    for col in MANUAL_CHICKEN_COLUMNS:
        if col not in result.columns:
            result[col] = ""
        result[col] = result[col].fillna("").astype(str).str.strip()

    path = existing_fin_product_map_review_csv_path()
    if not path.exists():
        return result
    try:
        prev = pd.read_csv(path, dtype=str, encoding="utf-8-sig").fillna("")
    except Exception as e:
        logger.warning("기존 검수 파일 로드 실패, 수기 컬럼 보존 생략: %s", e)
        return result
    if not any(col in prev.columns for col in MANUAL_CHICKEN_COLUMNS):
        return result

    prev = prev.reindex(columns=[*KEY_COLUMNS, *MANUAL_CHICKEN_COLUMNS], fill_value="")
    for col in KEY_COLUMNS:
        prev[col] = prev[col].fillna("").astype(str).str.strip()
    prev["source"] = prev["source"].map(canonical_source)   # load 경로와 키 일치 필수

    manual_by_key = {
        tuple(row[col] for col in KEY_COLUMNS): {
            col: _strip_text(row.get(col)) for col in MANUAL_CHICKEN_COLUMNS
        }
        for row in prev.to_dict("records")
    }

    restored = 0
    for idx in result.index:
        key = tuple(_strip_text(result.at[idx, col]) for col in KEY_COLUMNS)
        values = manual_by_key.get(key)
        if not values or not any(values.values()):
            continue
        for col in MANUAL_CHICKEN_COLUMNS:
            result.at[idx, col] = values[col]
        restored += 1

    logger.info(
        "닭 사용량 수기 보존: %d행 (신규 %d행)",
        restored,
        int(len(result) - restored),
    )
    return result
```

주의: `prev["source"]`에 `canonical_source()`를 반드시 적용해야 `load_review_map()`(line 404)과 키가 일치한다.

### 4. 검증 함수 `_validate_chicken_usage(df) -> int`

`write_review_map()`의 최종 `to_csv` 직전에 호출. **경고만 남기고 값을 자동 수정하거나 행을 제외하지 않는다.**

경고 대상:
- `닭유형_manual`이 `VALID_CHICKEN_TYPES` 밖 (빈칸 제외)
- `사이즈_manual`이 `VALID_CHICKEN_SIZES` 밖 (빈칸 제외)
- `닭사용량_manual`이 `float()` 파싱 불가

- 3컬럼 모두 유효한데 `CHICKEN_USAGE_TABLE[(닭유형, 사이즈)]`와 값이 다름

def load_review_map() -> pd.DataFrame:
    review_path = existing_fin_product_map_review_csv_path()
    if not review_path.exists():
        return _empty_review_map()
    df = pd.read_csv(review_path, dtype=str, encoding="utf-8-sig").fillna("")
    df = _apply_review_status_aliases(df)
    df = _apply_edit_column_aliases(df)
    df = df.reindex(columns=REVIEW_INTERNAL_COLUMNS, fill_value="")
    if "source" in df.columns:
        df["source"] = df["source"].fillna("").astype(str).str.strip().map(canonical_source)
    if "item_key" in df.columns and "item_name" in df.columns:
        df["item_key"] = df["item_key"].fillna("").astype(str).str.strip().where(
            df["item_key"].fillna("").astype(str).str.strip() != "",
            df["item_name"].fillna("").astype(str).map(normalize_item_key),
        )
    df[REVIEW_STATUS_COLUMN] = df[REVIEW_STATUS_COLUMN].apply(_normalize_review_status)
    return df


def write_review_map(review_df: pd.DataFrame) -> None:
    FIN_PRODUCT_MAP_REVIEW_CSV_PATH.parent.mkdir(parents=True, exist_ok=True)
    tmp = FIN_PRODUCT_MAP_REVIEW_CSV_PATH.with_suffix(".tmp")
    try:
        output_df = review_df.reindex(columns=REVIEW_INTERNAL_COLUMNS, fill_value="").copy()
        if "item_key" in output_df.columns and "item_name" in output_df.columns:
            output_df["item_key"] = output_df["item_key"].fillna("").astype(str).str.strip().where(
                output_df["item_key"].fillna("").astype(str).str.strip() != "",
                output_df["item_name"].fillna("").astype(str).map(normalize_item_key),
            )
        output_df = _mark_duplicate_labels(output_df)
        output_df[REVIEW_STATUS_DISPLAY_COLUMN] = output_df[REVIEW_STATUS_COLUMN].apply(_normalize_review_status)
        output_df.reindex(columns=REVIEW_COLUMNS, fill_value="").to_csv(tmp, index=False, encoding="utf-8-sig")
        _safe_replace(tmp, FIN_PRODUCT_MAP_REVIEW_CSV_PATH)
    finally:
        try:
            tmp.unlink(missing_ok=True)
        except Exception:
            pass

### modules/transform/pipelines/db/DB_FinProduct_Map.py — build_review_rows (line 884~897)

```python
def build_review_rows(map_df: pd.DataFrame) -> pd.DataFrame:
    if map_df.empty:
        return _empty_review_map()
    result = map_df.reindex(columns=MAP_COLUMNS, fill_value="").copy()
    result["검수사유"] = result.apply(_review_reason, axis=1)
    if result.empty:
        return _empty_review_map()
    result = (
        result.reindex(columns=REVIEW_INTERNAL_COLUMNS, fill_value="")
        .drop_duplicates(subset=KEY_COLUMNS, keep="last")
        .sort_values(["store", "source", "검수사유", "item_name"])
        .reset_index(drop=True)
    )
    return _mark_duplicate_labels(result)
```

### 실사용 라운드트립 (사람이 수행 — 코드 완료 후 안내만 할 것)

1. DAG 1회 실행 → CSV 끝에 빈 수기 컬럼 3개가 붙었는지 확인
2. 엑셀에서 몇 행에 `뼈닭` / `대` / `1.5` 입력 후 저장 (utf-8-sig 유지)
3. DAG 재실행
4. 입력값이 남아있고 로그에 `닭 사용량 수기 보존: N행` 이 찍히는지 확인

## Constraints

- `MAP_COLUMNS`, `JOIN_COLUMNS`, `RECENTLY_COLUMNS`에 수기 컬럼 추가 **금지** — LLM 격리가 깨진다
- `DB_FinProduct.py`의 `_MAP_ENRICHMENT_COLS`, few-shot `required` 튜플 **변경 금지**
- 검증 로직은 **경고만** — 수기값을 자동 수정하거나 해당 행을 제외하지 말 것 (사람의 입력이 최종 권위)
- 기존 컬럼 순서·이름 변경 금지 (엑셀 검수 파일 포맷 호환). 신규 컬럼은 **맨 뒤에만** 추가
- CSV 입출력은 `encoding="utf-8-sig"` 고정
- `dtype=str`로 읽어 숫자 자동 변환 방지 (`1.5` → `1.5` 문자열 유지)
- `_safe_replace()`의 PermissionError 재시도 로직 유지 (엑셀 파일 열려있을 때 대응)
- 마이그레이션 스크립트를 새로 만들지 말 것 — `reindex(fill_value="")`가 구 스키마를 자동 흡수한다
- 닭 사용량을 매출에 곱해 소요량을 집계하는 파이프라인은 **이번 범위 밖**. 입력 자리와 보존 장치까지만.

## Do Not Ask — Decide Yourself

- 파일이 이미 존재하면: 덮어쓰기
- import가 모호하면: Reference Code의 패턴 따라가기
- 타입 힌트 여부: 기존 파일과 동일하게 (`def f(df: pd.DataFrame) -> pd.DataFrame:`)
- 주석 여부: 최소화 (WHY만, WHAT 설명 금지)
- 변수명·함수명 스타일: snake_case, private helper는 `_` 접두어
- 로그 메시지 언어: 한국어 (기존 파일과 동일)
