# 쿠팡 확장 수집기 자동로그인 "권한이 존재하지 않습니다" 실패 수정

## Task
`doridang_collector_개발용` 크롬 확장(MV3)의 64계정 배치가 첫 계정·첫 시도부터 로그인 단계에서 `해당하는 요청을 처리할 권한이 존재하지 않습니다` 로 실패해 전혀 수집을 못 한다. 이 문구는 팬텀이 아니라 **Akamai 봇판정 거절**이며(수동 로그인은 정상), `runner.js`가 이를 rate-limit 쓰로틀로 오탐해 10분 쿨다운·3연속 배치중단으로 악화시킨다. 오탐을 제거(Part 1)하고 자동로그인이 Akamai를 통과하도록 인간형 입력·워밍업을 추가(Part 2)한다.

## Project Conventions (크롬확장 / JS)
- 언어: 브라우저 확장 JS(MV3). Python/Airflow 아님.
- 로깅: 확장 페이지는 기존 `log(msg, level)` 헬퍼 사용, content script는 `console.log`. 기존 패턴 그대로.
- 파일 인코딩: UTF-8 유지(한글 로그 다수). BOM 넣지 말 것.
- 기존 함수/변수 스타일(camelCase, `async/await`) 유지. 새 상수는 파일 상단 상수 블록 근처에 배치.
- 배민/요기요/땅기요 분기는 **절대 건드리지 않음**(쿠팡 분기만 수정).
- 세미콜론·들여쓰기 등 주변 코드 스타일 그대로.

```js
async function typeLikeHuman(el, text) {

}
```

### Part 2c — _abck 보존 (2a/2b로도 부족할 때만)
`runner.js` `clearSession`(line 792-802)의 전체 쿠키 삭제를 **선택 삭제**로 바꿔 Akamai 쿠키를 보존한다. 전 계정 인증 쿠키는 반드시 지워야 매장 오인이 없으므로 전체보존은 불가.
```js
async function clearSession() {
  const KEEP = new Set(['_abck', 'bm_sz', 'bm_sv', 'ak_bmsc']); // Akamai 센서 쿠키 보존
  const domains = ['https://store.coupangeats.com', 'https://advertising.coupangeats.com'];
  try {
    for (const url of domains) {
      const cookies = await chrome.cookies.getAll({ url });
      for (const c of cookies) {
        if (KEEP.has(c.name)) continue;
        await chrome.cookies.remove({ url, name: c.name });
      }
    }
    await new Promise(res => chrome.browsingData.remove(
      { origins: domains }, { localStorage: true }, () => res()));
  } catch (e) { log(`세션 초기화 오류(무시): ${e.message}`); }
  return true;
}
```
그리고 `manifest.json` `permissions`에 `"cookies"` 추가.

```js
async function clearSession() {
  return new Promise(resolve => {
    try {
      chrome.browsingData.remove(
        {origins:['https://store.coupangeats.com','https://advertising.coupangeats.com']},
        {cookies:true, localStorage:true},
        () => resolve(true)

  });

async function waitForLoginResult(tabId, ms, errorGraceMs = 0) {
  const deadline = Date.now() + ms;
  const errorEligibleAt = Date.now() + errorGraceMs;
  while (Date.now() < deadline) {
    if (stopRequested) return 'stop';
    const url = await getUrl(tabId);
    if (RE_ORDERS.test(url)) return 'ok';
    if (RE_LOGIN.test(url)) {
      try {
        const res = await chrome.scripting.executeScript({
          target: { tabId },
          func: () => {
            const s = document.querySelector('span.login-error-text');
            return (s && s.offsetParent !== null && s.textContent.trim().length > 0)
              ? s.textContent.trim() : '';
          }
        });
        const txt = res?.[0]?.result;
        if (txt && Date.now() >= errorEligibleAt) { lastLoginErrText = txt; return 'error'; }
      } catch(_) {}
    }
    await sleep(800);
  }
  return 'timeout';
}
```

## Test Cases
라이브(사용자 실기 크롬) 필수 — Akamai는 실기에서만 재현됨. Codex는 코드 정합성까지 자동 검증하고, 라이브 항목은 사용자에게 실행 요청.

1. **JS 문법 검사(자동)** — `runner.js`, `content/04_auto_login.js` 수정 후 파싱 오류 없어야 함. `node --check "<파일>"` → 기대: 출력 없음(exit 0). (경로에 공백/한글 있으므로 따옴표 필수)
2. **키워드 제거 확인(자동)** — `runner.js`에 `권한이 존재하지` 문자열이 `LOGIN_THROTTLE_KEYWORDS` 배열 안에 없어야 함 → 기대: grep 미검출.
3. **Part 1 라이브(사용자)** — 배치 재실행 → `쓰로틀 쿨다운 10분`·`연속 로그인 스로틀 3회` 로그가 **안 뜨고** 배치가 계정 끝까지 진행 → 기대: 배치가 중간에 안 죽음(성공 0이어도 통과).
4. **Part 2 라이브 1매장(사용자)** — 단일 계정 1개로 실행 → `orders 페이지 도달` 로그 출력, `권한이 존재하지 않습니다` 스팬 미발생 → 기대: 로그인 성공.
5. **대조(사용자)** — 같은 크롬에서 수동 로그인 여전히 정상(IP 밴 아님 재확인).

## Verification Loop
```
LOOP until all PASS:
  1. Test 1,2 (자동: node --check + grep) 실행
  2. FAIL 항목 → 원인 분석 → 코드 수정 → 재실행
  3. 자동 PASS 후 Test 3 라이브 요청 → 죽지 않으면 Test 4 요청
  4. Test 4 실패 시 레버 추가 순서: 2a(워밍업) → 2b(인간형입력) → 2c(_abck보존)
종료 조건: Test 1-4 PASS + 배민/요기요 분기 무변경
```
