## Project Conventions

- 순수 JS (빌드 스텝 없음, 트랜스파일 없음). 파일 저장 → `chrome://extensions` 새로고침이 배포 전부.
- 로깅 2종:
  - content script(`content/*.js`): `Utils.updateProgressModal({ debug: '...' })`
  - runner(`runner.js`): `log(msg, level)` — level은 `'ok' | 'err' | 'info'` (생략 시 기본)
- `console.log`/`console.debug` 는 화면 로그에 안 잡히므로 **잡음 강등 용도로 사용**한다.
- 문자열은 한글 그대로 쓴다 (`runner.js` 일부에 `\uXXXX` 이스케이프가 섞여 있으나 신규 코드는 한글 리터럴).
- 이모지 프리픽스 관례: `✅` 성공 / `⚠️` 경고 / `❌` 실패 / `⛔` 차단 / `⏳` 대기 / `ℹ️` 정보 / `📋` 큐
- 상수는 파일 상단 블록에 이미 모여 있다. **새 상수 추가보다 기존 유틸 재사용을 우선**한다.
- `sleep(ms)` 는 `runner.js` 에 이미 존재. content script는 `this._randomDelay(min, max)`.

### B1. CMG 0원 재조회가 매번 실패하는 문제 — `content/03_coupangeats.js`

`_collectCMGRowsWithRetry` (L1297) → `_clickSearchButton` (L410).

`_clickSearchButton` 은 `.calendar-dropdown` / `.calendar-dropdown-button` 을 찾는데,
CMG 결과가 이미 렌더된 화면에서는 날짜 드롭다운이 닫혀 있어 이 셀렉터가 존재하지 않는다.
게다가 5회 재시도 간격이 300~500ms라 총 2초 미만 — SPA 재렌더 대기 효과가 전혀 없다
(로그 증거: `03:01:18 → 03:01:20` 에 5줄이 몰려 있음).

**구현 전 실측 필수 (아래 Test Cases 1번). 셀렉터를 추측해서 넣지 말 것.**

1. 시그니처를 `async _clickSearchButton(doc, opts = {})` 로 변경.
   기존 호출부(다른 위치)는 인자 없이 호출하므로 하위 호환됨.
2. 재시도 횟수 5 → 3, 간격을 지수 백오프로. 즉시 5연타는 봇 탐지 관점에서도 불리하다.

```js
const MAX_SEARCH_ATTEMPT = 3;
for (let attempt = 0; attempt < MAX_SEARCH_ATTEMPT; attempt++) {
  // ... 기존 탐색 로직 ...
  console.debug(`[쿠팡이츠] 조회 버튼 찾기 실패 (시도 ${attempt + 1}/${MAX_SEARCH_ATTEMPT})`);
  const backoff = 300 * Math.pow(2, attempt);   // 300 → 600 → 1200ms
  await this._randomDelay(backoff, backoff + 200);
}
if (!opts.silent) {
  Utils.updateProgressModal({ debug: '❌ 조회 버튼을 찾을 수 없음' });
}
return false;
```

3. `_collectCMGRowsWithRetry` 의 재조회 경로는 **Test Cases 1번 실측 결과에 따라 둘 중 하나**로 확정:
   - **(a) 드롭다운이 열리는 트리거 요소를 찾은 경우**: 조회 버튼 탐색 전에 그 요소를 먼저 클릭해
     드롭다운을 연 뒤 `_clickSearchButton(doc, { silent: true })` 호출.
   - **(b) 트리거를 못 찾은 경우**: 재조회 자체를 포기한다. CMG 0원은 대부분 "광고 미집행"이라는
     정상 케이스이므로 아래로 강등:

```js
const clicked = await this._clickSearchButton(doc, { silent: true });
if (!clicked) {
  Utils.updateProgressModal({ debug: `ℹ️ CMG 0원 (광고 미집행 가능) — 재조회 생략 (${selectedStore} / ${dateStr})` });
  return pageRows;
}
```

어느 쪽이든 하루 5~8세트 / 30~48줄의 가짜 에러가 사라진다.

        const label = `${btn.getAttribute('aria-label') || ''} ${btn.getAttribute('title') || ''} ${btn.textContent || ''}`.trim();
        return /next|다음|›|>|»/i.test(label);
      });
    const isHidden = !nextBtn || nextBtn.classList.contains('hide-btn');
    const isDisabled = nextBtn?.disabled || nextBtn?.getAttribute('aria-disabled') === 'true';
    if (!nextBtn || isHidden || isDisabled) {
      Utils.updateProgressModal({ debug: `다음 페이지 버튼 사용 불가 - ${this._ordersDiag({ targetPage, hasNextBtn: !!nextBtn, hidden: !!isHidden, disabled: !!isDisabled })}` });

      if (this._clickPageNumber(targetPage)) return true;

function sanitizeDownloadFilename(filename, msg) {
  const raw = String(filename || '').trim();
  const safe = raw.replace(/[\\/:*?"<>|]+/g, '_').replace(/^\.+/, '').replace(/\s+/g, ' ').trim();
  if (!safe) return fallbackDownloadFilename(msg);
  if (!/\.[A-Za-z0-9]{1,8}$/.test(safe)) {
    const ext = String(msg?.mimeType || '').includes('text/plain') ? 'txt' : 'csv';

  }
  return safe;
}
