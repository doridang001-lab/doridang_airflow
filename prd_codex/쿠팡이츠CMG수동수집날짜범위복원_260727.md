# 쿠팡이츠 CMG 수동수집 날짜범위 복원

## Task

쿠팡이츠 CMG 페이지(`store.coupangeats.com/merchant/management/cmg/?cmg_revamp=%2F`)에서 팝업/단축키 수동수집 시 날짜범위 prompt를 다시 띄운다.

현재 수동 CMG 경로는 페이지 달력 텍스트를 조용히 읽고, `05_main.js`가 수동 실행에도 `targetDateMode: 'yesterday'`를 주입해 기존 prompt 분기가 사실상 도달 불가가 된다. 달력 읽기 실패가 `error:true`로 runner F5 루프를 타면 수동 실행이 어제로 수렴한다.

목표는 다음 3가지다.

- CMG 수동수집은 실행 시 날짜범위 prompt를 띄우고 입력받은 범위를 하루씩 수집한다.
- 사용자 취소/입력 오류는 `stopped:true, error:false`로 끝내 F5 재시도를 막는다.
- runner 대시보드 배치수집의 어제/오늘 판정은 `_isDashboardBatchOrders(opts)` 기준으로 그대로 유지한다.

- 수동 취소를 `return`만 하는 단일매장 경로와 `_sendCMGComplete(..., true, false)`를 보내야 하는 다중매장 경로를 구분해야 한다.

## Implementation

### 1. CMG 날짜 prompt 헬퍼 추가

`03_coupangeats.js`에 `_promptCMGDateRange(selectedStoreLabel = '')`를 추가했다.

- 기존 인라인 prompt 문구와 `_parseDateRange()` 계약을 재사용한다.
- `_parseDateRange()`가 이미 오늘/미래 날짜를 어제로 clamp하므로 호출부에서 추가 clamp를 하지 않는다.
- 시작일이 종료일보다 늦으면 헬퍼 안에서만 swap한다.
- 반환값은 `{ startDate, endDate, mode } | null`이다.

### 2. 다중매장 CMG 수동 날짜 결정부 교체

`_collectCMGMultiStore()`에서 수동 실행 전에 `_readCMGDateRange(doc)`를 호출하던 흐름을 제거했다.

- 달력 버튼 자체가 없으면 날짜 클릭이 불가능하므로 `error:true`로 runner F5 재시도를 유지한다.
- 배치 실행은 `_resolveBatchTargetDate(opts)`로 어제/오늘 단일 날짜를 결정한다.
- 수동 실행은 `_promptCMGDateRange(matchingStores.join(', '))`로 범위를 입력받는다.
- prompt 취소/오류는 `_sendCMGComplete(0, 0, true, false)`로 종료해 F5 루프를 막는다.

### 3. 단일매장 CMG 날짜 결정부 교체

`_collectCMGData()`의 3중 분기를 2중 분기로 정리했다.

- 배치: `_isDashboardBatchOrders(opts)`일 때만 `_resolveBatchTargetDate(opts)` 사용.
- 수동: `_promptCMGDateRange(selectedStore)` 사용.
- 기존 인라인 prompt 블록, 수동 달력 읽기, `opts.targetDate || opts.targetDateMode` 기반 clamp를 제거했다.
- `parseResult.mode`는 rolling week 라벨 계산을 위해 `{ mode: range.mode }`로 유지한다.

### 4. 달력 읽기 실패 로그 보강

`_readCMGDateRange(doc)`는 수동 경로에서는 더 이상 호출하지 않지만, 남아 있는 진단 용도를 위해 실패 로그를 추가했다.

- `.calendar-dropdown-input` 없음
- `.start-date`/`.end-date` 텍스트 파싱 실패

### 5. 수동 실행의 `yesterday` 기본값 제거

`05_main.js`의 `runCollector()` 인자에서 수동 실행은 `targetDateMode`를 빈 문자열로 넘기도록 바꿨다.

```js
targetDateMode: source === 'batch' ? (msg.targetDateMode || 'yesterday') : (msg.targetDateMode || ''),
```

`chrome.storage.local.set({ ce_current_target_date_mode: ... })`는 기존처럼 `source === 'batch'` 가드 안에만 있어 변경하지 않았다.

6. `-26.07.20` 입력 시 2026-07-14부터 2026-07-20까지 7일이 수집되는지 확인한다.
7. `26.07.27` 입력 시 2026-07-26 하루로 clamp되는지 확인한다.
8. prompt 취소 시 F5 재시도 없이 종료되는지 확인한다.
9. runner 대시보드 어제 수집은 prompt 없이 어제 하루 CMG 수집을 유지하는지 확인한다.
10. 주문서 페이지 수동수집은 날짜 영역을 클릭하지 않는 기존 규칙이 유지되는지 확인한다.
