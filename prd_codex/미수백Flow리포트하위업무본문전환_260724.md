# 미수백 Flow 리포트 하위업무 본문 전환

## Task
미수백(미나리 수삼 백숙) 매출 리포트를 Flow 고정 게시글(https://flow.team/l/QB1Na)의 **댓글(remark)** 방식에서 **하위업무(subtask) 본문** 방식으로 전환한다. 매일 1회 DAG 실행이 일별 하위업무 생성 + 이번 ISO 주(주간) + 이번 달(월간) 하위업무를 모두 upsert(없으면 추가, 있으면 갱신)하며, 사람이 적은 수기 메모 섹션은 보존한다.

## Implementation Steps

1. **집계 함수** (`susam_report.py`)
   - 기존 `build_report_frame`(일별) 유지 → `build_daily_frame`로 재사용/개명.
   - `load_susam_range(dates: list[str]) -> pd.DataFrame`: `UNIFIED_ROOT / f"unified_sales_{YYMMDD}.parquet"` 여러 개 읽어 concat(없는 파일 skip, `.bak_*` 제외) → `item_name.str.contains("수삼")` 필터 → 수치 정규화.
   - `build_weekly_frame(frame)`: 매장별/날짜별 집계. `build_monthly_frame(frame)`: 주차별/날짜별/매장별 TOP.
   - ISO 주 라벨 헬퍼: `dates.dt.strftime("%Y-W%V")` 기반, 월 내 순번(W#)으로 제목/표 단일화.

2. **본문 HTML 빌더** — CKEditor용 리스트/표 HTML, 동적 텍스트는 `html.escape`
   - `build_daily_body_html(date_str, frame) -> str` (매장·상품·수량·매출 표)
   - `build_weekly_body_html(year, week, frame) -> str` (집계기간/합계/날짜별·매장별 표)
   - `build_monthly_body_html(ym, frame) -> str` (주차별/날짜별/매장별 TOP)
   - 주/월 본문 끝에 수기 메모 sentinel 삽입: `<h2>📝 이벤트·활동 기록 (수기 입력)</h2>` (HTML 주석 아님 — CKEditor가 주석 제거 가능)

3. **메모 보존 병합**
   - `merge_preserving_memo(existing_html, new_auto_html, sentinel) -> str`: 기존 본문에 sentinel heading이 있으면 그 이후(수기 메모)를 유지하고 앞(자동 데이터)만 교체. 없으면 `new_auto_html` + 빈 메모 템플릿.

4. **하위업무 Selenium 함수** — 댓글 함수(`_find_comment_input`/`_set_comment_text`/`_submit_comment_*`/`upload_to_flow`/`upload_many_to_flow`)를 하위업무 함수로 교체. `Sales_Orders_09_FlowReport_Dags.py`에서 이식:
   - `_find_subtask_by_title(driver, title)` (`p.subtask__tit--display` 텍스트 매칭)
   - `_add_subtask(driver, title)` (`button.js-add-subtask-button` → non-readonly `input.js-subtask-input` JS 세팅 + Enter 이벤트)
   - `_open_subtask_editor(driver, title)` (제목 클릭 → `button.js-setting-button.set-btn` → 수정. selector 두 형태 대응: `li.js-setting-item[data-code='modify']` **또는** `i.post-edit-icon` 포함 `a` 앵커. CKEditor ready 대기)
   - `_read_editor_html(driver)` / `_set_editor_html(driver, html)` (마지막 인스턴스 `CKEDITOR.instances[keys[keys.length-1]]` getData/setData, iframe fallback)
   - `_submit_editor(driver)` (`button.js-complete-btn.confirm`)
   - `upsert_subtask(driver, title, auto_html, *, preserve_memo)`: find→(없으면 add)→open→(preserve면 read+`merge_preserving_memo`)→setData→submit

5. **`main(argv)` 재구성** — 인자 표면 유지(`--date/--start/--end/--post-url/--debugger-address/--force/--no-upload`)
   - `target_dates` 계산 → `_create_driver(debugger_address=...)` 1개 생성 → `driver.get(post_url)` → login 리다이렉트 검사
   - 각 date: `upsert_subtask("[데이터] {date} 미수백 일별 판매", daily_html, preserve_memo=False)`
   - 이번 ISO 주: `upsert_subtask("[집계-주] {YYYY-MM} W# 미수백 주간 현황", weekly_html, preserve_memo=True)`
   - 이번 달: `upsert_subtask("[집계-월] {YYYY-MM} 미수백 월간 현황", monthly_html, preserve_memo=True)`
   - 반환 dict에 `"failed"` 키 유지. `flow_susam_uploaded.json` 상태파일 의존 제거(미사용) — DOM find-or-create가 idempotency 소스, `--force`는 기존 하위업무 재편집.

6. **DAG** (`Strategy_SusamReport_01_FlowUpload_Dags.py`)
   - 태스크 체인 그대로: `wait_for_source_ready >> wait_for_flow_chrome >> upload_daily_report >> release_flow_chrome`
   - `_upload_daily_report`는 새 `main` 인자/반환에 맞춰 조정만. description/tags 문구를 "본문/하위업무"로 갱신. debugger-attach 인프라·종료 마커(`flow_susam_chrome_release.json`) 유지.

def _create_driver(user_data_dir, profile, debugger_address=None):
    from selenium import webdriver
    from selenium.webdriver.chrome.options import Options
    options = Options()
    if debugger_address:
        options.add_experimental_option("debuggerAddress", debugger_address)
    else:
        options.add_argument(f"--user-data-dir={Path(user_data_dir).expanduser().resolve()}")
        options.add_argument(f"--profile-directory={profile}")
    options.add_argument("--no-sandbox")
    options.add_argument("--disable-dev-shm-usage")
    options.add_argument("--window-size=1920,1080")
    # FLOW_CHROMEDRIVER_PATH 있으면 Service 사용, 없으면 기본→webdriver_manager fallback

### dags/sales/Sales_Orders_09_FlowReport_Dags.py (하위업무 add → 수정 → CKEditor → 등록, 이식 원본)
```python
# ③ + 하위업무 추가
add_subtask_btn = wait.until(EC.presence_of_element_located(
    (By.CSS_SELECTOR, "button.js-add-subtask-button")))
driver.execute_script("arguments[0].click();", add_subtask_btn)

# ④ non-readonly input에 JS 세팅 + Enter 이벤트 (send_keys 금지)
subtask_input = wait.until(lambda d: next(
    (el for el in d.find_elements(By.CSS_SELECTOR, "input.js-subtask-input")
     if not el.get_attribute("readonly")), None))
driver.execute_script("""
    var el = arguments[0], title = arguments[1];
    el.focus(); el.value = title;
    el.dispatchEvent(new Event('input', {bubbles: true}));
    el.dispatchEvent(new Event('change', {bubbles: true}));
    el.dispatchEvent(new KeyboardEvent('keydown', {key:'Enter', keyCode:13, bubbles:true}));
    el.dispatchEvent(new KeyboardEvent('keyup', {key:'Enter', keyCode:13, bubbles:true}));
""", subtask_input, title)

# ⑤ 생성된 하위업무 클릭 → ⑥ 설정 → ⑦ 수정
for item in driver.find_elements(By.CSS_SELECTOR, "p.subtask__tit--display"):
    if title in item.text:
        driver.execute_script("arguments[0].click();", item); break
setting_btn = wait.until(EC.element_to_be_clickable(
    (By.CSS_SELECTOR, "button.js-setting-button.set-btn")))
driver.execute_script("arguments[0].click();", setting_btn)
modify_item = wait.until(EC.element_to_be_clickable(
    (By.CSS_SELECTOR, "li.js-setting-item[data-code='modify']")))
driver.execute_script("arguments[0].click();", modify_item)

# ⑧ CKEditor 마지막 인스턴스 setData (iframe fallback)
driver.execute_script("""
    var keys = Object.keys(CKEDITOR.instances);
    CKEDITOR.instances[keys[keys.length - 1]].setData(arguments[0]);
""", body_html)

# ⑨ 등록
submit_btn = wait.until(EC.presence_of_element_located(
    (By.CSS_SELECTOR, "button.js-complete-btn.confirm")))
driver.execute_script("arguments[0].click();", submit_btn)
```

## Test Cases
1. [주간 집계] `python -m pytest tests/test_susam_report.py -k weekly -q` → 기대: PASS (매장별/날짜별 합계 정확)
2. [월간 집계] `python -m pytest tests/test_susam_report.py -k monthly -q` → 기대: PASS (주차별 합계 = 날짜별 합계)
3. [메모 보존] `python -m pytest tests/test_susam_report.py -k memo -q` → 기대: sentinel 있으면 메모 유지, 없으면 빈 템플릿 생성
4. [전체 유닛] `python -m pytest tests/test_susam_report.py -q` → 기대: 전체 PASS
5. [dry-run] `python scripts/analysis/susam_report.py --date 2026-07-23 --no-upload` → 기대: CSV 생성 + 일/주/월 HTML 로깅, 업로드 없음, exit 0
6. [DAG import] `python -c "from dags.strategy.Strategy_SusamReport_01_FlowUpload_Dags import dag"` → 기대: ImportError 없음
7. [실 업로드·수동] 호스트 Chrome이 대상 게시글에 뜬 상태에서 `python scripts/analysis/susam_report.py --date 2026-07-23 --post-url https://flow.team/l/QB1Na --debugger-address 127.0.0.1:9223` → 기대: `[데이터] 2026-07-23` / `[집계-주] 2026-07 W#` / `[집계-월] 2026-07` 하위업무 생성·갱신. `--force` 재실행 시 중복 없이 갱신 + 주/월 수기 메모 유지.

## Verification Loop
```
LOOP until all PASS:
  1. Test Cases 1~6 순서대로 실행 (7은 수동 확인 항목)
  2. FAIL 항목 → 원인 분석
  3. 코드 수정
  4. 전체 재실행
종료 조건: Test 1~6 전체 PASS + Constraints 위반 없음
```

## Constraints
- CKEditor는 HTML 주석을 제거할 수 있으므로 메모 sentinel은 가시 heading 텍스트로 사용.
- 하위업무 "수정" 진입 DOM이 게시글 subtask와 프로젝트 subtask에서 다를 수 있어 selector 두 형태(`data-code='modify'` / `i.post-edit-icon` 앵커) 모두 시도.
- W# 라벨은 단일 헬퍼로 산출해 제목과 본문 표가 어긋나지 않게 함.
- debugger-attach 세션이라 `driver.quit()`는 호스트 Chrome을 닫지 않음(종료는 마커 담당) — 기존 동작 유지.
- DAG 오케스트레이션/센서/태스크 체인/마커 흐름은 변경 금지.
- subtask input은 send_keys 금지 → JS 이벤트 디스패치만.
