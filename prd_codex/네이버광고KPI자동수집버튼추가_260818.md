# 네이버 광고(ads.naver.com) KPI 자동 수집 버튼 추가

## Task

## Project Conventions
- 이 프로젝트는 Airflow/Python이 아니라 **크롬 확장(순수 JS, MV3)** 이다. Python 규칙 적용 금지.
- 콘텐츠 스크립트 로드 순서 고정: `00_config.js`(전역 `Utils={}`,`Sites={}`) → `01_utils.js`(Utils 채움) → 플랫폼 모듈(`02_baemin.js`,`03_coupangeats.js`,`07_naver.js`,`08_yogiyo.js`, 이번에 `09_naverads.js` 추가) → `04_auto_login.js` → `05_main.js`(메시지 핸들러/디스패치) → `06_batch.js`
- 플랫폼 모듈 규약: `Sites['name'] = { name, match(url), _stopFlag, async collect(opts), ... }`. 디스패치는 `05_main.js`의 `runCollector()`가 런타임에 `site.match(url)`로 수행 → **js 배열 등록 순서는 무관**.
- 메시지 계약: 러너/팝업 `--COLLECT-->` `05_main.js` → `Sites[x].collect()`; 콘텐츠 `--DOWNLOAD_CSV-->` `background.js`(이번 기능은 이 경로를 쓰지 않음, 아래 네이티브 다운로드 경로 참고); 라이브 로그는 `{type:'LIVE_LOG', msg}`.
- `Utils`는 **콘텐츠 스크립트 전용 전역** — 러너(`runner_*.js`)에서는 사용 불가. 러너는 자체 로컬 유틸을 소량 작성.
- 클래스명은 CSS-in-JS 해시일 수 있음 → **절대 클래스 매칭 금지**. `data-row-key`, `role="switch"`, `aria-checked`, `data-origin` 같은 안정적 속성/구조 기반 셀렉터를 우선 사용한다(과업 지시에 첨부된 실제 HTML에 이 속성들이 이미 존재함을 확인함).
- ⚠️ 이 경로는 OneDrive 동기화 폴더다. `*-DESKTOP-*` 백업 파일은 **절대 수정 금지**.
- `C:\airflow\coupang_extension_build`는 오래된 미러이며 이번 작업과 무관 — 건드리지 않는다.

## Implementation Steps

### 1. `content/09_naverads.js` — 추출 모듈 (`08_yogiyo.js` 구조 + `07_naver.js` 매칭 스타일)
`Sites['naverads']`를 등록한다. `location.href`로 목록/상세 페이지를 구분해 분기한다.

```js
Sites['naverads'] = {
  name: '네이버 광고 KPI',
  match: (url) => url.includes('ads.naver.com/manage/ad-accounts/'),
  _stopFlag: false,

  async collect(opts = {}) {
    this._stopFlag = false;
    try {
      if (location.href.includes('/all-campaigns')) {
        const mode = opts.naverAdsMode || 'discover';
        if (mode === 'nextPage') return await this._clickNextPage();
        return await this._discoverPage();
      }
      if (location.href.includes('/sa/campaigns/')) {
        return await this._downloadCurrentCampaign(opts);
      }
      this._sendComplete({ success:false, errorCode:'UNKNOWN_PAGE', error:'지원하지 않는 페이지' });
    } catch (e) {
      const error = String(e?.message || e);
      this._sendLiveLog(`네이버광고 수집 예외: ${error}`);
      this._sendComplete({ success:false, errorCode:'COLLECT_ERROR', error });
    }
  },

  // ── 목록 페이지: "상세 데이터" 1회 클릭(실패해도 계속) → 상태 대기 → row 파싱 ──
  async _discoverPage() {
    await this._tryOpenDetailColumns();
    const ready = await this._waitForRows(20000);
    if (!ready) {
      this._sendMessage('NAVERADS_DISCOVER_PAGE', { success:false, errorCode:'ROWS_NOT_FOUND', error:'캠페인 목록을 찾지 못함' });
      return;
    }
    const rows = this._parseRows();
    const hasNext = this._hasNextPage();
    this._sendLiveLog(`목록 파싱: ${rows.length}건 (다음 페이지: ${hasNext ? '있음' : '없음'})`);
    this._sendMessage('NAVERADS_DISCOVER_PAGE', { success:true, rows, hasNext });
  },

  async _clickNextPage() {
    const before = this._rowKeySnapshot();
    const nextBtn = this._nextPageButton();
    if (!nextBtn) {
      this._sendMessage('NAVERADS_DISCOVER_PAGE', { success:false, errorCode:'NEXT_BUTTON_NOT_FOUND', error:'다음 페이지 버튼을 찾지 못함' });
      return;
    }
    this._clickInteractive(nextBtn);
    const changed = await this._waitForRowsChanged(before, 15000);
    if (!changed) {
      this._sendMessage('NAVERADS_DISCOVER_PAGE', { success:false, errorCode:'PAGE_CHANGE_TIMEOUT', error:'페이지 전환 대기 타임아웃' });
      return;
    }
    // 다음 discover 호출은 러너가 별도로 보낸다 - 여기선 전환 성공만 보고
    this._sendMessage('NAVERADS_NEXTPAGE_DONE', { success:true });
  },

  // "상세 데이터" 드롭다운 트리거 — 정확한 효과가 불확실하므로 실패해도 무시하고 진행.
  // 최초 실행 라이브 로그로 실제 동작을 확인해 필요시 이 함수만 보정한다.
  async _tryOpenDetailColumns() {
    try {
      const btn = [...document.querySelectorAll('button')]
        .find(el => this._isVisible(el) && this._normalizeText(el.textContent) === '상세 데이터');
      if (btn) { this._clickInteractive(btn); await this._sleep(300); }
    } catch (e) {
      this._sendLiveLog(`상세 데이터 버튼 클릭 실패(무시): ${e.message}`);
    }
  },

  async _waitForRows(timeoutMs) {
    const deadline = Date.now() + timeoutMs;
    while (Date.now() < deadline) {
      if (this._stopFlag) return false;
      if (document.querySelectorAll('tr[data-row-key]').length) return true;
      await this._sleep(400);
    }
    return false;
  },

  _rowKeySnapshot() {
    return [...document.querySelectorAll('tr[data-row-key]')].map(tr => tr.dataset.rowKey).join(',');
  },

  async _waitForRowsChanged(beforeSnapshot, timeoutMs) {
    const deadline = Date.now() + timeoutMs;
    while (Date.now() < deadline) {
      if (this._stopFlag) return false;
      const now = this._rowKeySnapshot();
      if (now && now !== beforeSnapshot) return true;
      await this._sleep(400);
    }
    return false;
  },

  _parseRows() {
    return [...document.querySelectorAll('tr[data-row-key]')].map(tr => {
      const campaignId = tr.dataset.rowKey || '';
      const link = tr.querySelector('a[data-origin]');
      const name = this._normalizeText(link?.textContent);
      const toggle = tr.querySelector('button[role="switch"]');
      const on = toggle?.getAttribute('aria-checked') === 'true';
      const cells = [...tr.querySelectorAll('td')].map(td => this._normalizeText(td.textContent));
      const type = cells[5] || ''; // 구분(파워링크/플레이스 등) 열 - 실제 인덱스는 최초 실행 로그로 검증
      return { campaignId, name, on, type };
    }).filter(row => row.campaignId);
  },

  _nextPageButton() {
    const nextLi = document.querySelector('li.ad-cms-pagination-next');
    if (!nextLi || nextLi.getAttribute('aria-disabled') === 'true') return null;
    return nextLi.querySelector('button');
  },

  _hasNextPage() {
    return !!this._nextPageButton();
  },

  // ── 상세 페이지: 다운로드 버튼 클릭 (드롭다운 메뉴가 뜨면 첫 항목 클릭) ──
  async _downloadCurrentCampaign(opts) {
    const expectedId = String(opts.expectedCampaignId || '');
    if (expectedId && !location.href.includes(expectedId)) {
      this._sendComplete({ success:false, errorCode:'CAMPAIGN_MISMATCH', error:`URL에 ${expectedId} 없음: ${location.href}` });
      return;
    }
    const btn = await this._waitForDownloadButton(20000);
    if (!btn) {
      this._sendComplete({ success:false, errorCode:'DOWNLOAD_BUTTON_NOT_FOUND', error:'다운로드 버튼을 찾지 못함' });
      return;
    }
    this._clickInteractive(btn);
    this._sendLiveLog('다운로드 버튼 클릭');
    await this._sleep(500);
    const menuItem = this._firstVisibleMenuItem();
    if (menuItem) {
      this._sendLiveLog('다운로드 형식 메뉴 감지 - 첫 항목 클릭');
      this._clickInteractive(menuItem);
    }
    this._sendComplete({ success:true, clicked:['download'], campaignId:expectedId });
  },

  async _waitForDownloadButton(timeoutMs) {
    const deadline = Date.now() + timeoutMs;
    while (Date.now() < deadline) {
      if (this._stopFlag) return null;
      const btn = [...document.querySelectorAll('button')]
        .find(el => this._isVisible(el) && this._normalizeText(el.textContent) === '다운로드');
      if (btn) return btn;
      await this._sleep(400);
    }
    return null;
  },

  _firstVisibleMenuItem() {
    const items = [...document.querySelectorAll('[role="menu"] [role="menuitem"]')].filter(el => this._isVisible(el));
    return items[0] || null;
  },

  _normalizeText(value) { return String(value || '').replace(/\s+/g, ' ').trim(); },

  _clickInteractive(element) {
    const target = element.closest('button, [role="button"], a') || element;
    for (const type of ['pointermove', 'pointerdown', 'mousedown', 'mouseup', 'pointerup', 'click']) {
      const event = type.startsWith('pointer')
        ? new PointerEvent(type, { bubbles:true, cancelable:true, view:window })
        : new MouseEvent(type, { bubbles:true, cancelable:true, view:window });
      target.dispatchEvent(event);
    }
  },

  _isVisible(element) {
    if (!element || !element.isConnected) return false;
    const style = getComputedStyle(element);
    return style.display !== 'none' && style.visibility !== 'hidden' && style.opacity !== '0' && element.getClientRects().length > 0;
  },

  _sleep(ms) { return new Promise(resolve => setTimeout(resolve, ms)); },

  _sendMessage(type, payload) {
    try { const r = chrome.runtime.sendMessage({ type, payload }); if (r?.catch) r.catch(() => {}); } catch (_) {}
  },
  _sendLiveLog(msg) {
    try { const r = chrome.runtime.sendMessage({ type:'LIVE_LOG', msg }); if (r?.catch) r.catch(() => {}); } catch (_) {}
  },
  _sendComplete(payload) {
    try { const r = chrome.runtime.sendMessage({ type:'NAVERADS_COMPLETE', payload }); if (r?.catch) r.catch(() => {}); } catch (_) {}
  }
};
```
> 열 인덱스(`cells[5]`), "상세 데이터" 버튼의 실제 효과, 다운로드 버튼 클릭 시 메뉴 등장 여부는 **1차 실행 라이브 로그로 반드시 검증**하고 필요시 이 파일만 보정한다.

### 3. `runner_naverads.js` — 오케스트레이션 (discover → collect 2-phase)
`runner_yogiyo.js`의 탭 헬퍼(`waitTabComplete`, `injectContent`, `sleepWithStop`, `log`, `getUrl`)와 다운로드 예약 패턴(`reserveDownload`/`waitForDownload`/`settleDownload`)을 그대로 이식하되 메시지 타입을 `NAVERADS_*`로 바꾼다.

```js
(() => {
  'use strict';
  const ACCOUNT_ID = '1497096';
  const LIST_URL = `https://ads.naver.com/manage/ad-accounts/${ACCOUNT_ID}/all-campaigns`;
  const detailUrlFor = (campaignId) => `https://ads.naver.com/manage/ad-accounts/${ACCOUNT_ID}/sa/campaigns/${campaignId}`;
  const CONTENT_FILES = ['content/00_config.js', 'content/01_utils.js', 'content/09_naverads.js', 'content/05_main.js'];
  const DOWNLOAD_TIMEOUT = 60000;

  let stopRequested = false, pendingDiscover = null, pendingComplete = null, pendingDownload = null;

  // ── discover 단계 ──
  async function discoverAll(tabId) {
    const campaigns = [];
    let hasNext = true;
    while (hasNext) {
      if (stopRequested) break;
      const page = await sendDiscover(tabId, 'discover');
      if (!page.success) { log(`discover 실패: ${page.error}`); break; }
      campaigns.push(...page.rows);
      hasNext = page.hasNext;
      if (hasNext) {
        const advanced = await sendDiscover(tabId, 'nextPage');
        if (!advanced.success) { log(`페이지 전환 실패: ${advanced.error}`); break; }
      }
    }
    return campaigns;
  }

  function sendDiscover(tabId, mode) {
    return new Promise(async (resolve) => {
      pendingDiscover = { settled:false, resolve };
      const timer = setTimeout(() => { if (!pendingDiscover.settled) { pendingDiscover.settled = true; resolve({ success:false, error:'timeout' }); } }, 30000);
      pendingDiscover._timer = timer;
      try { await chrome.tabs.sendMessage(tabId, { type:'COLLECT', source:'batch', naverAdsMode:mode }); }
      catch (e) { clearTimeout(timer); pendingDiscover.settled = true; resolve({ success:false, error:e.message }); }
    });
  }

  // ── collect 단계 (요기요 waitForDownload 패턴과 동일, 타입만 NAVERADS_*) ──
  function reserveDownload(campaign) {
    return chrome.runtime.sendMessage({ type:'NAVERADS_EXPECT_DOWNLOAD', accountId:ACCOUNT_ID, campaignId:campaign.campaignId, campaignName:campaign.name });
  }
  function clearReservedDownload() {
    return chrome.runtime.sendMessage({ type:'NAVERADS_CLEAR_DOWNLOAD' }).catch(() => {});
  }
  function waitForComplete(timeoutMs = 30000) {
    return new Promise(resolve => {
      pendingComplete = { settled:false, resolve, timer:setTimeout(() => settleComplete({ success:false, error:'timeout' }), timeoutMs) };
    });
  }
  function settleComplete(payload) {
    if (!pendingComplete || pendingComplete.settled) return;
    pendingComplete.settled = true; clearTimeout(pendingComplete.timer);
    const resolve = pendingComplete.resolve; pendingComplete = null; resolve(payload);
  }
  function waitForDownload(timeoutMs = DOWNLOAD_TIMEOUT) {
    return new Promise(resolve => {
      pendingDownload = { settled:false, resolve, timer:setTimeout(() => settleDownload({ success:false, error:'timeout' }), timeoutMs) };
    });
  }
  function settleDownload(payload) {
    if (!pendingDownload || pendingDownload.settled) return;
    pendingDownload.settled = true; clearTimeout(pendingDownload.timer);
    const resolve = pendingDownload.resolve; pendingDownload = null; resolve(payload);
  }

  chrome.runtime.onMessage.addListener((msg) => {
    if (msg?.type === 'LIVE_LOG') { log(msg.msg); return; }
    if (msg?.type === 'NAVERADS_DISCOVER_PAGE' && pendingDiscover && !pendingDiscover.settled) {
      pendingDiscover.settled = true; clearTimeout(pendingDiscover._timer); pendingDiscover.resolve(msg.payload); return;
    }
    if (msg?.type === 'NAVERADS_NEXTPAGE_DONE' && pendingDiscover && !pendingDiscover.settled) {
      pendingDiscover.settled = true; clearTimeout(pendingDiscover._timer); pendingDiscover.resolve(msg.payload); return;
    }
    if (msg?.type === 'NAVERADS_COMPLETE') { settleComplete(msg.payload || {}); return; }
    if (msg?.type === 'NAVERADS_DOWNLOAD_SAVED') { settleDownload({ success:true, ...msg }); return; }
    if (msg?.type === 'NAVERADS_DOWNLOAD_FAILED') { settleDownload({ success:false, error:msg.error, ...msg }); return; }
  });

  async function run() {
    stopRequested = false;
    log(`계정 ${ACCOUNT_ID} 캠페인 목록 수집 시작`);
    const tab = await chrome.tabs.create({ url: LIST_URL, active:false });
    await waitTabComplete(tab.id);
    await injectContent(tab.id);

    const all = await discoverAll(tab.id);
    const targets = all.filter(c => c.on);
    log(`총 ${all.length}개 발견 (ON ${targets.length} / OFF ${all.length - targets.length}, 스킵)`);

    let ok = 0, fail = 0;
    for (const campaign of targets) {
      if (stopRequested) { log('중단됨'); break; }
      log(`▶ ${campaign.name} (${campaign.campaignId}) 처리…`);
      await chrome.tabs.update(tab.id, { url: detailUrlFor(campaign.campaignId) });
      await waitTabComplete(tab.id);
      if (!await injectContent(tab.id)) { fail++; log(`✗ content 주입 실패: ${campaign.name}`); continue; }

      await reserveDownload(campaign);
      const completeWaiter = waitForComplete(30000);
      const downloadWaiter = waitForDownload(DOWNLOAD_TIMEOUT);
      try { await chrome.tabs.sendMessage(tab.id, { type:'COLLECT', source:'batch', naverAdsMode:'download', expectedCampaignId:campaign.campaignId }); }
      catch (e) { log(`COLLECT 전송 실패: ${e.message}`); }

      const clickResult = await completeWaiter;
      if (!clickResult.success) { fail++; log(`✗ ${campaign.name}: ${clickResult.error || clickResult.errorCode}`); await clearReservedDownload(); settleDownload({ success:false }); continue; }

      const downloadResult = await downloadWaiter;
      if (!downloadResult.success) { fail++; log(`✗ ${campaign.name} 다운로드 확인 실패: ${downloadResult.error}`); continue; }

      ok++; log(`✓ ${campaign.name} 저장 완료: ${downloadResult.filename || '-'}`);
      await sleepWithStop(1000 + Math.floor(Math.random() * 1000));
    }

    if (fail === 0) { try { await chrome.tabs.remove(tab.id); } catch (_) {} }
    log(`완료: 성공 ${ok} / 실패 ${fail}`);
  }

  // waitTabComplete / injectContent / sleepWithStop / log / getUrl 는
  // runner_yogiyo.js 343~391행 패턴을 그대로 이식 (CONTENT_FILES만 위 상수로 교체)
})();
```

```js
chrome.downloads.onDeterminingFilename.addListener((downloadItem, suggest) => {
  const filename = pendingDownloadNamesByUrl.get(downloadItem.url);
  if (!filename) {
    const reservation = currentYogiyoReservation();
    if (!reservation || !isYogiyoReservedDownloadCandidate(downloadItem)) return;
    const ext = yogiyoDownloadExt(downloadItem);
    const store = safeFilenamePart(pendingYogiyoDownload.store) || 'store';
    const yogiyoFilename = `yogiyo_settlement_${store}_${todayCompact()}.${ext}`;
    pendingYogiyoDownloadNamesById.set(downloadItem.id, yogiyoFilename);
    pendingYogiyoDownload = null;
    chrome.runtime.sendMessage({ type: 'YOGIYO_DOWNLOAD_STARTED', downloadId: downloadItem.id }).catch(() => {});
    suggest({ filename: yogiyoFilename, conflictAction: 'uniquify' });
    return;
  }
  suggest({ filename, conflictAction: 'uniquify' });
});

chrome.downloads.onChanged.addListener((delta) => {
  if (!delta?.id || delta.state?.current !== 'complete') return;
  const expectedName = pendingYogiyoDownloadNamesById.get(delta.id);
  if (!expectedName) return;
  pendingYogiyoDownloadNamesById.delete(delta.id);
  chrome.downloads.search({ id: delta.id }, (items) => {
    const item = items?.[0] || {};
    const hasPositiveSize = Number(item.fileSize ?? -1) > 0 || Number(item.totalBytes ?? -1) > 0;
    if (item.exists !== true || !hasPositiveSize) {
      chrome.runtime.sendMessage({ type: 'YOGIYO_DOWNLOAD_FAILED', filename: item.filename, downloadId: delta.id, error: '파일 확인 실패' }).catch(() => {});
      return;
    }
    chrome.runtime.sendMessage({ type: 'YOGIYO_DOWNLOAD_SAVED', filename: item.filename, downloadId: delta.id, exists: item.exists, fileSize: item.fileSize, totalBytes: item.totalBytes }).catch(() => {});
  });
});

// 메시지 핸들러 (YOGIYO_EXPECT_DOWNLOAD / YOGIYO_CLEAR_DOWNLOAD / YOGIYO_CHECK_RESERVATION)
if (msg?.type === 'YOGIYO_EXPECT_DOWNLOAD') {
  pendingYogiyoDownload = { store: msg.store || '', accountId: msg.accountId || '', month: msg.month || '', ts: Date.now() };
  sendResponse({ success: true });

}
```

## Constraints
- Airflow/Python 규칙 적용 금지 — 순수 JS 크롬 확장.
- `Utils`(콘텐츠 전용 전역)를 러너에서 직접 호출하지 말 것. 러너는 로컬 유틸(`waitTabComplete`,`injectContent`,`sleepWithStop`,`log`)을 자체 보유.
- 클래스명 CSS-in-JS 해시 가능성 → **정확 클래스 매칭 금지**. `data-row-key`/`role="switch"`/`aria-checked`/`data-origin` 등 안정 속성 기반 셀렉터만 사용.
- 목록 URL 재방문 시 페이지네이션이 1페이지로 리셋될 수 있으므로, **collect 단계에서는 상세 URL로 직접 이동만 하고 목록으로 돌아가지 않는다** (discover 단계에서 이미 전체 캠페인 ID를 확보했으므로 불필요).
- 계정 1497096 하드코딩, 다중 계정 확장은 이번 범위 아님.
- OFF 캠페인은 다운로드 대상에서 제외 — discover 로그에만 스킵 사유 기록.
- 기존 `DOWNLOAD_CSV` 핸들러 및 요기요 관련 코드는 수정하지 않는다 — `NAVERADS_*` 네임스페이스로 추가만 한다.
- `*-DESKTOP-*` 백업 파일 절대 수정 금지. 변경 최소화.
- "상세 데이터" 버튼의 실제 효과, 다운로드 버튼의 메뉴 등장 여부는 미확인 상태 — 실패해도 다음 단계를 막지 않게 만들고 최초 실행 라이브 로그로 검증 후 필요시만 보정.
