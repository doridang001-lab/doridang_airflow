def _target_date_from_context(context) -> str:

### modules/transform/pipelines/db/DB_Beamin_05_ad_funnel.py (현재 — 교체 대상)

```python
_FILTER_BTN_CSS   = "button.Filter-module__lRdH"
_METRIC_LABELS    = ["노출수", "클릭수", "주문수", "주문금액"]
_FILTER_LABEL_MAP: dict[int, list[str]] = {
    # 2026-07 현재 화면 DOM 순서. 화면 개편 전의 설명과 순서가 반대다.
    0: ["주문수", "주문금액"],
    1: ["노출수", "클릭수"],
}

def _extract_filter_vals(driver, btn_idx: int, store_name: str) -> list[str] | None:
    vals: list[str] = driver.execute_script(
        """
        const btns = document.querySelectorAll('button.Filter-module__lRdH');
        const btn = btns[arguments[0]];
        if (!btn) return [];
        let el = btn.parentElement;
        for (let i = 0; i < 8; i++) {
            if (!el || el === document.body) break;
            const nums = [...el.querySelectorAll('span')]
                .map(s => s.textContent.trim())
                .filter(v => /^[\\d,]+$/.test(v));
            const filters = [...el.querySelectorAll('button.Filter-module__lRdH')];
            if (filters.length > 1 && nums.length >= (arguments[0] + 1) * 2) {
                return nums.slice(arguments[0] * 2, arguments[0] * 2 + 2);
            }
            if (filters.length <= 1 && nums.length >= 2) return nums.slice(0, 2);
            el = el.parentElement;
        }
        return [...document.querySelectorAll('span[style*="margin"]')]
            .map(s => s.textContent.trim())
            .filter(v => /^[\\d,]+$/.test(v))
            .slice(arguments[0] * 2, arguments[0] * 2 + 2);
        """,
        btn_idx,
    ) or []
    logger.info("Filter[%d] vals extracted: %s / %s", btn_idx, vals, store_name)
    if len(vals) == 0:
        logger.warning("Filter[%d] metrics missing in DOM: %s", btn_idx, store_name)
        return None
    return vals
```

### modules/transform/pipelines/db/DB_Beamin_05_ad_funnel.py — 유지할 검증기

```python
def _metrics_are_plausible(metrics: dict) -> bool:
    values = {label: _metric_int(metrics.get(label)) for label in _METRIC_LABELS}
    if any(value is None for value in values.values()):
        return False
    impressions = int(values["노출수"]); clicks = int(values["클릭수"])
    orders = int(values["주문수"]);     order_amount = int(values["주문금액"])
    if clicks > impressions: return False
    if orders > clicks: return False
    if orders > 0 and clicks == 0: return False
    if order_amount > 0 and orders == 0: return False
    return True
```

## Constraints

- **`_extract_filter_vals`의 `["0","0"]` fallback을 되살리지 말 것.** 값 미검출은 실패로 남겨야 오염 데이터가 다시 쌓이지 않는다. 이게 이번 사태의 근본 교훈이다.
- **Step 1 DOM 진단 로그로 실제 구조를 확인하기 전에 Step 2 선택자를 추측으로 작성하지 말 것.** 현재 코드가 실패하는 이유가 정확히 "index 기반 추측"이다.
- **`_metrics_are_plausible`를 완화하거나 제거하지 말 것.** 라벨 뒤바뀜을 잡는 유일한 안전망이다.
- **`DB_Beamin_03_shop_change.py`를 통째로 삭제하지 말 것.** 운영시간(shop_operation) 수집이 같은 파일에 있고 `DB_Beamin_monthly_operation`의 1순위 소스다.
- **`BAEMIN_SHOP_CHANGE_DB` 상수와 기존 shop_change CSV를 삭제하지 말 것.** `DB_Beamin_monthly_operation`이 히스토리로 계속 읽는다.
- **renderer timeout / 테이블 로드 타임아웃 / 합계 불일치 로직은 건드리지 말 것.** 07-22 이전과 동일 수준이고 재시도로 자가복구된다. 이번 실패와 무관하다.
- `NOW`·`우가클`·`주문내역` 수집 경로는 정상 동작 중이므로 변경 금지.
- `_should_collect_shop_change`를 운영시간 수집에 재사용하지 말 것 — 운영시간은 토요일 한정이 아니라 기존 `used_store_hint` 조건만 따른다.
