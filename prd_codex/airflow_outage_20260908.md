## 재발 방지

- Docker 감시를 하루 1회에서 5분 간격으로 변경. HTTP 200만으로 정상 판정하지 않고 DB/스케줄러 및 8개 컨테이너 health 확인.
- 3회 연속 비정상일 때 복구, 재기동 간격 30분 제한, 프로세스 잠금 및 중단 전 상태 저장 적용.
- CLI 호출별 timeout 처리. 숨김 pythonw 실행에서 잘못된 표준입력 핸들 상속으로 Docker CLI가 멈추는 문제는 `stdin=DEVNULL`로 해결. 예약 작업 실제 실행 성공 확인.
- C: 여유 공간 30GiB 미만일 때 미사용 VM 블록 반환을 최대 6시간당 1회 수행. 10GiB 미만이면 자동 재시작 보류 및 로컬 상태/로그 기록.
- 상태: `.tmp/docker_watchdog/state.json`, 로그: `.tmp/docker_watchdog/watchdog.log`.
- 새 외부 알림 전송은 추가하지 않음. 저용량/복구 실패는 위 상태 파일과 작업스케줄러 종료 코드로 확인.
- 워커는 부하 중 Docker healthcheck 10초 제한을 넘겨도 실제 `pong`을 반환하는 경우가 있었음. 별도 45초 유예 ping으로 실제 응답을 확인해 수집 중 오탐 재기동을 방지.
