```python
_SIZE_TAG_RE    = re.compile(r"^(?:소|중|대|특|[0-9]+\s*~?\s*[0-9]*\s*인|[0-9]+인분|반마리|한마리|뼈|순살)$")
_LEADING_TAG_RE = re.compile(r"^\s*[\[\(（【]\s*([^\]\)）】]{1,20})\s*[\]\)）】]\s*")

def _strip_leading_tags(s: str) -> str:
    while True:
        m = _LEADING_TAG_RE.match(s)
        if not m:
            return s
        inner = m.group(1).strip()
        if _SIZE_TAG_RE.fullmatch(inner):     # [소], [3~6인] 등 사이즈·인원은 보존
            return s
        s = s[m.end():].strip()
```

### modules/transform/pipelines/db/DB_UnifiedSales_common.py:1059-1079 — `_make_unified_pk`
```python
def _make_unified_pk(df: pd.DataFrame) -> pd.Series:
    """unified_sales 전용 PK 생성 (소스/스키마 공통).

    PK 구성:
    - sale_date | source | store | platform | order_id | item_seq
    """
    for col in ("sale_date", "source", "store", "platform", "order_id", "item_seq"):
        if col not in df.columns:
            df[col] = ""
    key = (
        df["sale_date"].fillna("").astype(str).str.strip()
        + "|" + df["source"].fillna("").astype(str).str.strip()
        + "|" + df["store"].fillna("").astype(str).str.strip()
        + "|" + df["platform"].fillna("").astype(str).str.strip()
        + "|" + df["order_id"].fillna("").astype(str).str.strip()
        + "|" + df["item_seq"].fillna("").astype(str).str.strip()
    )
    return key.map(lambda s: hashlib.md5(s.encode()).hexdigest())
```


## Constraints

- **`UNIFIED_COLUMNS` 리스트를 절대 수정하지 말 것.** `DB_UnifiedSales_okpos.py:861`의
  `return merged[UNIFIED_COLUMNS]`가 strict 선택이라 컬럼을 추가하면 KeyError로 `build_okpos`가
  죽고 DAG 체인 전체가 멈춘다. import해서 복사만 한다.
- **`DB_UnifiedSales_*.py` 를 한 줄도 수정하지 말 것.** 읽기 전용.
- **`MART_DB/unified_sales_grp/` 에 절대 쓰지 말 것.**
- **상품테이블에 파일도 컬럼도 추가하지 말 것.** `fin_product_*.csv`는 읽기만.
  특히 `fin_product_alias.csv`를 새로 만들지 말고 `fin_product_map.csv`에서 메모리로 파생한다.
- **`NEW_CLS_DIR` 밖에는 아무것도 쓰지 말 것.**
- **송파삼전점 외 매장을 처리하지 말 것.** 매장은 코드 상수이고 conf로 바꿀 수 없어야 한다.
- **LLM 호출 금지.** 표준명은 규칙 + 사람 검수 데이터 조회로만 채운다. 안 풀리면 빈 값 + gap 리포트.
- `item_seq` 부여는 각 source의 기존 방식(`groupby("order_id").cumcount()+1`)을 그대로 따를 것.
  unified와 `_pk`가 일치해야 대조가 가능하다.
- posfeed boundary는 `"'+"`가 아니라 **`"'"` 한 글자**로 판정할 것 (`'-` 행도 자식).
- 쿠팡 `menu_price`는 float NaN이 문자열 `'nan'`으로 오므로 반드시 필터할 것.
- print 금지, 경로 하드코딩 금지.
