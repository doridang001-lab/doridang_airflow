# DB_MenuHierarchy_Test 완전분류 운영 기준

## 목적

송파삼전점 전체 주문을 메뉴별 닭사용량과 품목별 수익 입력에 바로 쓸 수 있게 완전분류한다.
최종 산출물에는 `추정`, `충돌`, `입력필요`, `판정상태` 같은 신뢰도 표현을 노출하지 않는다.
대신 미분류가 1건이라도 남으면 `03_요약.xlsx`에서 확인하고, `01_수기입력.xlsx`의 `판정옵션`으로 확정한다.

## 최종 파일

OneDrive `new_classification_orders` 루트에는 4개만 둔다.

- `01_수기입력.xlsx`: 사람이 입력하는 유일한 파일
- `02_최종주문.csv`: 최종 주문별 분류 결과
- `03_요약.xlsx`: 메뉴별 닭사용량, 수익, source별 완전분류 검증
- `04_사용법.md`: 현장 사용법

기존 `10_orders.csv`부터 `28_manual_profit_summary.csv`까지의 CSV는 루트에 두지 않는다.
필요하면 `_debug/latest/`에만 생성하고, 과거 루트 CSV는 `_archive/legacy_csv_*`에 보관한다.

## 완전분류 원칙

주문 원천에는 행을 추가하지 않는다. 0원 옵션을 실제 주문행으로 만들면 `_pk`, `item_seq`, source별 원천 검증이 깨진다.

원천에 순살/뼈/사이즈가 없거나 충돌나는 경우는 `01_수기입력.xlsx`의 `판정옵션` 시트로 확정한다.
이 방식은 매출과 주문행은 그대로 유지하고, 분류 결과만 보정한다.

분류 우선순위:

1. 실제 주문 옵션/메뉴명 명시값
2. `예외보정` 시트의 주문그룹 직접 입력
3. `판정옵션` 시트의 source별 메뉴 기본값
4. 기존 메뉴 고정 규칙
5. 남으면 미분류로 보고 DAG 실패

최종 주문서에는 아래 최종 분석 컬럼만 본다.

- `닭유형`
- `사이즈`
- `사용용량`
- `사용용량_합계`
- `분류룰`

`분류룰` 예시는 `확정:수기`, `확정:메뉴명`, `확정:판정옵션`, `확정:닭미사용`이다.

## 수기입력 파일

`01_수기입력.xlsx` 시트 역할:

- `수익률`: 품목별 수익률 입력. 예: `품목|콜라`의 `수익률_manual=0.36`
- `메뉴중량`: 메뉴, 사이즈, 닭유형별 닭/재료 사용량 입력
- `옵션분류`: 옵션/사이드/음료/재료추가 성격 확정
- `재료단가`: 공헌이익 계산용 재료 단가
- `뼈순살비율`: 원천 신호가 약한 조합의 뼈비율 수기값
- `판정옵션`: 옵션 없음/충돌/사이즈 없음 주문을 완전분류로 확정
- `옵션재료`: 유가 옵션의 재료 사용량
- `예외보정`: 주문그룹 단위 직접 보정

`판정옵션` 필수 컬럼:

- `source`
- `brand`
- `store`
- `std_menu_name`
- `조건`
- `닭옵션키`
- `닭유형`
- `사이즈`
- `사용용량`
- `메모`

`조건` 값은 `옵션없음`, `사이즈옵션없음`, `닭유형충돌`, `사이즈충돌`, `자동보정`을 쓴다.

## 검증 기준

완전분류 성공 조건:

- `02_최종주문.csv` 행 수와 `_pk` unique가 동일
- source별 매출 합계 불변
- main 기준 `미분류행=0`
- `03_요약.xlsx > 미분류_TOP` 0행
- blocking issue 0건

2026-08-10 검증 결과:

- `02_최종주문.csv`: 31,663행
- `_pk` unique: 31,663
- 매출합계: 177,571,719
- source별 완전분류율: okpos 100%, 배민수동 100%, 쿠팡수동 100%, posfeed 100%
- `미분류_TOP`: 0행
- `판정옵션_적용결과`: 72개 룰
- `확정:판정옵션` 적용 main 행: 631행
- blocking issue: 0건

남은 WARN:

- `profit_missing`: 수익률/단가/중량 입력 전 상태
- `completeness_regression`: 수익·재료 입력 대기 기준선 후퇴 WARN

이 WARN은 메뉴/닭유형/사이즈/사용량 분류 실패가 아니다.

## 운영 순서

1. `DB_MenuHierarchy_Test_Dags` 실행 또는 `build_orders(None)` 실행
2. `03_요약.xlsx > source별_분류검증`에서 `미분류행` 확인
3. `미분류_TOP`에 행이 있으면 `01_수기입력.xlsx > 판정옵션`을 채움
4. 다시 실행
5. `미분류_TOP`이 0행이면 완전분류 완료
6. 수익 분석은 `수익률` 시트에 값을 채운 뒤 다시 실행

## 주의

- 실제 주문행에 0원 옵션을 추가하지 않는다.
- `판정옵션`은 분류 전용 룰이며 매출/주문건수에는 영향을 주면 안 된다.
- `02_최종주문.csv`의 `분류룰=확정:판정옵션`은 원천에 없던 정보를 운영 기준으로 확정했다는 뜻이다.
- 전체 매장 확장 시에도 먼저 source별 `미분류행`을 0으로 만드는 것이 우선이다.
