# 배민 메뉴판 수동수집

## Task

배민 셀프서비스 메뉴판 페이지(`https://self.baemin.com/shops/{shopId}/menupan`)에서
메뉴명·배달판매가·판매상태·적용매장을 CSV로 저장하는 기능을 크롬 확장에 추가한다.
사용자가 직접 메뉴판 페이지를 열어둔 상태에서 `/` 단축키(또는 팝업·확장 아이콘)로 실행하는
**수동수집**이며, 로그인/매장선택 자동화는 하지 않는다.
파일명은 Airflow 파이프라인이 바로 읽는 규격 `[브랜드][매장명]baemin_menu_YYYY-MM-DD.csv`를 쓴다.

## Project Conventions

작업 대상은 Airflow 리포가 아니라 **크롬 확장(MV3) 폴더**다.

- 작업 루트: `C:\Users\민준\OneDrive - 주식회사 도리당\Extention\doridang_collector_개발용`
- 지침 원본: 해당 폴더의 `AGENTS.md` (CLAUDE.md는 포인터일 뿐)
- 로깅: `console.log('[Collector] ...')` / `console.warn` — 기존 접두어 유지
- 수집 로직은 `content/02_baemin.js`의 `Sites['baemin']` 객체 메서드로 추가 (`_` 접두 private 관례)
- CSV 생성은 반드시 `Utils.toCSV(headers, rows)` 사용 (직접 문자열 조립 금지)
- 파이프라인 규격 저장은 `window.BaeminPipelineSave._download(csv, filename)` 재사용
- UI 피드백은 `Utils.showProgress(title, message)` / `Utils.showSuccess(message, detail)` / `Utils.showError(title, message)`
- 대기는 `this._randomDelay(min, max)` 재사용 (새 sleep 헬퍼 만들지 않는다)
- 변수/함수명 camelCase, 컬럼명·사용자 노출 문자열은 한글 (기존 파일과 동일)
- 주석은 최소화 (WHY만)

### 2. `_getMenupanShopInfo()` 신설

기존 `_getShopInfo()`의 select 셀렉터는 구 클래스(`select.Select-module__a623`,
`select.ShopSelect-module___pC1`) 기준이라 메뉴판의 신형 클래스(`select.Select_b_ezkn_...`)를
잡지 못한다. 메뉴판 전용 보강본을 만든다.

```js
_getMenupanShopInfo() {
  const shopId = location.pathname.match(/\/shops\/(\d+)/)?.[1] || '';
  if (shopId) {
    for (const select of document.querySelectorAll('select')) {
      const option = [...select.options].find(o => String(o.value) === shopId);
      if (option) {
        const parsed = this._parseShopOption(option);   // 기존 헬퍼 재사용
        if (parsed?.store_name || parsed?.store_id) return parsed;
      }
    }
  }
  const fallback = this._getShopInfo();
  return { store_name: fallback.store_name || '', store_id: fallback.store_id || shopId, needFilter: false };
}
```

### 3. `_scrollCollectMenuItems(info)` 신설 — 가상 스크롤 수확기 (핵심)

메뉴판은 **가상 스크롤**이다. `.menuList-module__container--sqOv` 안 sizer div가
`height: 4812px`이고 각 항목은 `div[data-index][style*="translateY"]`로 절대배치되며,
**화면에 보이는 6~8개만 DOM에 존재**한다. 스크롤하지 않으면 전체 수집이 불가능하다.

```js
async _scrollCollectMenuItems(info) {
  const iso = new Date().toISOString();
  const collected = new Map();          // key: data-index (없으면 순번), value: row
  const container = this._findMenuScrollElement();

  const harvest = () => {
    let added = 0;
    const items = document.querySelectorAll('[data-index]');
    const nodes = items.length ? items : document.querySelectorAll('[class*="menuList-module__listItem"]');
    nodes.forEach((el, i) => {
      const key = el.getAttribute('data-index') ?? `seq-${i}`;
      if (collected.has(key)) return;
      const row = this._parseMenuItem(el, info, iso);
      if (row) { collected.set(key, row); added++; }
    });
    return added;
  };

  const scrollTopOf  = () => (container === document.scrollingElement ? window.scrollY : container.scrollTop);
  const viewportOf   = () => (container === document.scrollingElement ? window.innerHeight : container.clientHeight);
  const maxScrollOf  = () => container.scrollHeight - viewportOf();
  const scrollTo     = (y) => (container === document.scrollingElement ? window.scrollTo(0, y) : (container.scrollTop = y));

  const originalTop = scrollTopOf();
  let idleRounds = 0;

  for (let guard = 0; guard < 200; guard++) {
    if (this._stopFlag) break;
    const added = harvest();
    Utils.showProgress('메뉴판 수집 중...', `${collected.size}개 메뉴`);

    const atBottom = scrollTopOf() >= maxScrollOf() - 4;
    if (atBottom) {
      idleRounds = added === 0 ? idleRounds + 1 : 0;
      if (idleRounds >= 3) break;
    }
    scrollTo(Math.min(scrollTopOf() + viewportOf() * 0.7, maxScrollOf()));
    await this._randomDelay(350, 550);
  }

  scrollTo(originalTop);
  return [...collected.values()];
}
```

스크롤 컨테이너 판별 헬퍼도 같이 만든다. 스크롤 주체가 window인지 내부 div인지 페이지마다
다르므로 반드시 실측 판별한다.

```js
_findMenuScrollElement() {
  const doc = document.scrollingElement || document.documentElement;
  if (doc && doc.scrollHeight > doc.clientHeight + 50) return doc;

  let el = document.querySelector('[class*="menuList-module__container"]');
  while (el && el !== document.body) {
    const st = getComputedStyle(el);
    if (/(auto|scroll)/.test(st.overflowY) && el.scrollHeight > el.clientHeight + 50) return el;
    el = el.parentElement;
  }
  return doc;
}
```

### 4. `_parseMenuItem(el, info, iso)` 신설 — 항목 파서

**클래스명 해시 주의**: `menuInfo-module__name--BtnE`처럼 빌드 해시가 붙고 배포 때마다 바뀐다.
반드시 `[class*="접두"]` 부분일치 셀렉터만 쓴다. 완전일치 셀렉터 금지.

```js
_parseMenuItem(el, info, iso) {
  const text = node => (node?.textContent || '').replace(/\s+/g, ' ').trim();

  const 메뉴명 = text(el.querySelector('[class*="menuInfo-module__name"]'));
  if (!메뉴명) return null;

  // 배달 가격: cancelLine(정상가)·할인율(%) 스팬을 제외한 값이 실제 판매가
  let 배달판매가 = '';
  for (const row of el.querySelectorAll('[class*="priceListItem-module__row"]')) {
    const spans = [...row.querySelectorAll('span')].filter(s => !s.querySelector('span'));
    const label = text(spans[0]);
    if (label !== '배달') continue;
    const priceSpan = spans.find(s =>
      !(s.className || '').includes('cancelLine') &&
      /[\d,]+원/.test(text(s)) &&
      !/^\d+%$/.test(text(s))
    );
    if (priceSpan) 배달판매가 = Utils.cleanPrice(text(priceSpan));
    break;
  }

  // 상태: statusBox 텍스트 > 숨김 배지 > 판매중
  const statusBoxText = text(el.querySelector('[class*="menuList-module__statusBox"]'));
  const hidden = !!el.querySelector('[class*="menuInfo-module__hide"]');
  const 상태 = statusBoxText || (hidden ? '숨김' : '판매중');

  const 적용매장 = [...el.querySelectorAll('[class*="shopRowList-module__shop"]')]
    .map(text).filter(Boolean).join('|');

  return {
    collected_at: iso,
    store_name: info.store_name || '',
    store_id: info.store_id || '',
    메뉴명, 배달판매가, 상태, 적용매장
  };
}
```

### 6. `_collectMenupan(shopInfo)` 신설

```js
async _collectMenupan(shopInfo) {
  const info = this._getMenupanShopInfo();
  const storeName = info.store_name || shopInfo.store_name || '알수없는매장';

  Utils.showProgress('메뉴판 수집 중...', '메뉴 목록 스캔');
  const rows = await this._scrollCollectMenuItems({ ...info, store_name: storeName });

  if (!rows.length) {
    Utils.showError('데이터 없음', '수집할 메뉴 데이터가 없습니다.');
    return { success: false, error: '메뉴 데이터 없음' };
  }

  const csv = Utils.toCSV(window.BaeminPipelineSave.MENU_HEADERS, rows);
  const brand = window.BaeminPipelineSave._getBrand(storeName);
  const d = new Date();
  const today = `${d.getFullYear()}-${String(d.getMonth() + 1).padStart(2, '0')}-${String(d.getDate()).padStart(2, '0')}`;
  const filename = `[${brand}][${storeName}]baemin_menu_${today}.csv`;

  await window.BaeminPipelineSave._download(csv, filename);
  Utils.showSuccess('메뉴판 수집 완료', `${rows.length}건 → ${filename}`);

  return { success: true, filename, rows: rows.length, store_name: storeName, store_id: info.store_id || '' };
}
```

```js
_randomDelay(min, max) {
  const ms = Math.floor(Math.random() * (max - min + 1)) + min;

_parseShopOption(option) {
```

### content/01_utils.js — CSV / UI 헬퍼

```js
escapeCSV(val) {
  const str = String(val ?? '');
  return (str.includes(',') || str.includes('"') || str.includes('\n'))
    ? '"' + str.replace(/"/g, '""') + '"'
    : str;
},

cleanPrice(text) {
  if (!text) return '';
  return text.replace(/[^\d-]/g, '').replace(/^-/, '');
},

toCSV(headers, rows) {
  let csv = headers.join(',') + '\n';
  for (const row of rows) {
    csv += headers.map(h => this.escapeCSV(row[h])).join(',') + '\n';
  }
  return csv;
},
```

## Constraints

- **수정 파일은 `content/02_baemin.js` 하나뿐이다.** manifest·popup·runner·background 변경 금지.
- `*-DESKTOP-*` 백업 파일(`content/02_baemin-DESKTOP-HG136JL.js` 등)은 읽지도 수정하지도 않는다.
- 기존 카테고리(orders / woori / ad / change / now)의 동작을 바꾸지 않는다.
  분기 추가는 **기존 조건문 뒤에 append**만 한다.
- 해시가 붙는 CSS 모듈 클래스는 완전일치로 쓰지 않는다. 전부 `[class*="..."]` 부분일치.
- `while (true)` 무한 스크롤 금지 — 반드시 안전상한(200회) + `this._stopFlag`(ESC) 체크를 넣는다.
- 수집 종료 후 스크롤 위치를 원래대로 복원한다.
- OneDrive 폴더를 수정하므로 진행 전 사용자 승인을 받는다 (확장 폴더 `AGENTS.md` 규칙).
- 픽업가·할인율·정상가·이미지 URL 컬럼은 이번 범위 밖. 추가하지 않는다.
