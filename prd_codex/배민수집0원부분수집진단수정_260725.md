## Task
2026-07-23 배민 매크로에서 별도 계정 매장들이 배민=0/부분수집으로 ToOrder와 diff 발생.

## Implementation Steps

### F1 — 힌트경로에서 같은 지점의 sister brand도 함께 방출

**문제:** 계정명이 `도리당 경북상주점` 하나뿐이라 `_split_requested_store_name`이 브랜드 1개만 떼고,
`KNOWN_STORE_ID_BY_REQUEST`에서 `("도리당","경북상주점")` 만 조회 → `("나홀로","경북상주점")=#14850832` 누락.

**수정:** `_store_list_from_account_hint`의 **마지막 return 부분만** 교체. 나머지 로직은 그대로 둔다.

현재 (DB_Beamin_combined.py, 함수 끝부분):
```python
    store_id = str(account.get("store_id") or "").strip()
    if not store_id and brand:
        store_id = KNOWN_STORE_ID_BY_REQUEST.get((brand, store), "")

    if not (brand and store and store_id):
        return []
    return [{"store_id": store_id, "brand": brand, "store": store}]
```

수정 후 (마지막 `return` 만 아래로 교체):
```python
    store_id = str(account.get("store_id") or "").strip()
    if not store_id and brand:
        store_id = KNOWN_STORE_ID_BY_REQUEST.get((brand, store), "")

    if not (brand and store and store_id):
        return []

    result = [{"store_id": store_id, "brand": brand, "store": store}]
    # 계정명은 브랜드 접두어 1개만 담아 힌트경로가 sister brand(예: 나홀로 경북상주점)를 누락함 → 같은 지점의 다른 브랜드도 방출
    for (sister_brand, sister_store), sister_id in KNOWN_STORE_ID_BY_REQUEST.items():
        if sister_store == store and sister_brand != brand and sister_id:
            result.append({"store_id": str(sister_id), "brand": sister_brand, "store": store})
    return result
```

제약:
- `_split_requested_store_name`, `KNOWN_STORE_ID_BY_REQUEST`, 위쪽 `matches`/`lookup_store_key` 로직은 **변경 금지**.
- 단일브랜드 매장은 sister 루프가 아무것도 추가하지 않아 기존 동작과 동일해야 한다(회귀 없음).

### F2 — 빈/실패 수집이 기존 배민행을 삭제하지 못하게

**문제:** 수집 실패/빈스크레이프로 파일이 없으면 fallback이 `_upsert_daily(empty, …)`를 호출,
remove-mask가 기존 정상 배민행을 삭제 → 배민=0으로 덮임(R4).

**수정:** `_upsert_daily` 시그니처에 **keyword-only 기본값 인자 `verified_zero: bool = False`** 추가하고,
`df_new`가 빌 때 `verified_zero`가 아니면 **삭제를 보류**(기존행 보존)한다.
호출부는 수정하지 않는다(기본값 False = 보존).

```python
def _split_requested_store_name(requested_store_name: str) -> tuple[str | None, str]:
    value = str(requested_store_name or "").strip()
    for brand in KNOWN_BRANDS:               # KNOWN_BRANDS = ["도리당", "나홀로"]
        prefix = f"{brand} "
        if value.startswith(prefix):
            return brand, value[len(prefix):].strip()
    return None, value

def _store_list_from_account_hint(account: dict) -> list[dict]:
    requested_store_name = str(account.get("store_name") or "").strip()
    brand, store = _split_requested_store_name(requested_store_name)
    if not store:
        return []
    matches = re.findall(r"[가-힣]+(?:점|지점|분점|직영점)", store)
    if matches:
        store = matches[-1]
    if brand:
        store = lookup_store_key(brand, store)
    store_id = str(account.get("store_id") or "").strip()
    if not store_id and brand:
        store_id = KNOWN_STORE_ID_BY_REQUEST.get((brand, store), "")
    if not (brand and store and store_id):
        return []
    return [{"store_id": store_id, "brand": brand, "store": store}]   # ← 여기만 F1 교체
```

### DB_UnifiedSales_baemin.py (수정 대상 함수 앞부분)
```python
def _upsert_daily(df_new: pd.DataFrame, date: str, store: str) -> tuple[int, int]:
    UNIFIED_ROOT.mkdir(parents=True, exist_ok=True)
    daily_path = _unified_daily_path(date)
    if daily_path.exists():
        try:
            df_existing = pd.read_parquet(daily_path).reindex(columns=UNIFIED_COLUMNS, fill_value="")
        except Exception as exc:
            logger.warning("배민 교정 스킵, 기존 unified parquet 로드 실패: %s | %s", daily_path, exc)
            return 0, 0
        store_s = df_existing["store"].fillna("").astype(str).str.strip()
        platform_s = df_existing["platform"].fillna("").astype(str).str.strip()
        source_s = df_existing["source"].fillna("").astype(str).str.strip()
        remove_mask = store_s.eq(store) & platform_s.isin(BAEMIN_PLATFORMS)
        if df_new is None or df_new.empty:
            remove_mask = remove_mask & source_s.eq(BAEMIN_SOURCE)   # ← 여기만 F2 교체
        removed_count = int(remove_mask.sum())
        df_existing = df_existing[~remove_mask]
    else:
        df_existing = pd.DataFrame(columns=UNIFIED_COLUMNS)
        removed_count = 0
```
