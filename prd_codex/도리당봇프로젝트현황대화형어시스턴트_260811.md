# 도리당봇 — 프로젝트 현황 대화형 어시스턴트

## Task

리더가 Flow(협업툴) 프로젝트 진행상황을 대화로 물어보면, 실제 parquet 데이터를 근거로 답하는 내부 LLM 봇을 만든다.
로컬 `gpt-oss:20b`(Ollama)를 쓰고, 브라우저에서 링크로 접속하는 채팅 웹 UI를 제공한다.
모든 대화는 `log.md`에 누적되어 이후 질문에서 검색·참조된다.

## 사전 검증된 사실 (재조사 불필요, 그대로 신뢰할 것)

| 항목 | 실측 결과 |
|---|---|
| Ollama | 실행 중. `gpt-oss:20b`(131k ctx, tools+thinking), `qwen2.5:14b` |
| 생성 속도 | **78 tok/s** |
| Tool calling | 정상 동작. 한국어 질문에서 project_code 정확 추출 |
| Ollama 바인딩 | **`127.0.0.1:11434` 전용** — 외부 PC 직접 접근 불가 |
| 포트 | 8787 = 기존 대시보드 점유. **8788 사용** |
| 임베딩 모델 | `nomic-embed-text` **미설치** (이번 범위 아님) |

### 설계를 강제하는 제약 3가지

1. **크롬 확장은 Ollama를 직접 못 부른다.** `chrome-extension://` origin에 Ollama가 **403 Forbidden** 반환.
   확장은 로컬 파일(OneDrive parquet)도 못 읽는다. → 브릿지 서버가 반드시 필요하다.
2. **Ollama가 `127.0.0.1`에만 바인딩** → 브릿지 서버는 Ollama와 **같은 PC**에서 실행하고, 서버만 `0.0.0.0`로 연다.
3. **근거를 안 주면 환각한다.** 데이터 없이 "현황판 구축이 지연되고 있어"라고 묻자
   *"약 2주 지연, API 오류와 리소스 부족"* 이라고 지어냈다.
   → **자유 생성 금지. 반드시 tool 조회 결과만 근거로 답하게 한다.**

### 2. `tools.py` — parquet 조회 (환각 방지의 핵심)

```python
ALLOWED_PROJECTS = {
    "2926716": "[브랜드 전략기획부] 직영점 성장전략(온라인 유입)",
    "2926717": "[브랜드 전략기획부] 브랜드 바이럴",
    "2926713": "[브랜드 전략기획부] 회사 현황판 구축",
}
```

**⚠️ 반드시 지킬 2가지 함정 (실측으로 확인됨):**

1. **파티션 디렉터리를 pandas로 읽으면 `project_id`가 `int64`로 추론된다.**
   루트의 레거시 flat 파일은 `string`이다. 문자열로 비교하면 **조용히 0건**이 나온다.
   → 읽은 직후 반드시 `df["project_id"] = df["project_id"].astype(str)` 정규화.
2. **루트의 `flow_post.parquet` / `flow_comment.parquet` / `flow_project.parquet`는
   2026-08-03에 멈춘 stale 레거시 사본이다.**
   → 반드시 파티션 디렉터리(`FLOW_POST_PARQUET`, `FLOW_COMMENT_PARQUET`)를 읽는다.
   `FLOW_LEGACY_*` 상수는 **절대 사용 금지**.

구현할 함수 6종 (전부 `ALLOWED_PROJECTS` 밖이면 거부 메시지 반환):

| 함수 | 설명 |
|---|---|
| `list_projects()` | 3개 프로젝트 + 게시글/댓글 수 요약 |
| `get_project_status(project_id)` | `task_status` 집계, 담당자(`worker`)별, `end_dt` 기한 경과 건 |
| `search_posts(project_id, keyword)` | `title` + `content_text` 부분일치 검색 |
| `get_post_thread(post_id)` | `parent_post_id`/`depth`로 스레드 구성 + 댓글 전체 |
| `get_recent_activity(project_id, days)` | 최근 N일 상태 전이 이력 (아래 참조) |
| `search_conversation_log(keyword)` | `log.md` 키워드 검색 (conversation.py 위임) |

**상태 전이 이력 파싱:** `flow_comment`의 `is_system=True` 행이 `sys_code`에
`S45_2^^대기^^진행` 형태로 변경 이력을 담고 있다. `^^`로 split해서
`(이전상태, 이후상태)`를 추출하면 "지난주에 뭐가 움직였나"를 답할 수 있다.
`written_at`은 14자리 `YYYYMMDDHHMMSS` 문자열이다.

**날짜 포맷 주의:** `post_date`=`YYYY-MM-DD`, `start_dt`/`end_dt`=`YYYYMMDD`, `written_at`=`YYYYMMDDHHMMSS`.

### 6. `server.py` — ThreadingHTTPServer

`modules/transform/dashboard/server.py` 구조를 그대로 따른다 (Reference Code 참조).

| 라우트 | 메서드 | 설명 |
|---|---|---|
| `/health` | GET | `ok` 평문 |
| `/` | GET | `static/index.html` |
| `/static/*` | GET | 정적 파일 (경로 탈출 방지 필수) |
| `/api/chat` | POST | **SSE 스트리밍** 응답 |

**SSE 구현:**
- `Content-Type: text/event-stream`, `Cache-Control: no-cache`
- `Content-Length` 헤더 **금지** (스트리밍이므로)
- 청크마다 `data: {json}\n\n` 쓰고 `self.wfile.flush()`
- 종료 시 `data: [DONE]\n\n`

**Tool calling 루프:** 모델이 `tool_calls`를 내면 → `tools.py`에서 실행 →
결과를 `{"role":"tool", ...}`로 messages에 append → 재호출. **최대 5회 반복** 후 중단.
tool 실행 중에는 SSE로 `{"type":"tool","name":...}` 이벤트를 보내 UI에 "조회 중" 표시.

**CORS:** 2단계(크롬 확장) 대비해 `Access-Control-Allow-Origin` 헤더와 `OPTIONS` 핸들러를 미리 넣어둔다.

`DEFAULT_HOST = "0.0.0.0"`, `DEFAULT_PORT = 8788`, `python -m modules.transform.doridang_bot.server` 진입점.

### modules/transform/dashboard/server.py (서버 골격 — 이 구조를 그대로 따를 것)

```python
"""Combined dashboard server for DAG and harness monitoring."""
from __future__ import annotations

import json
import logging
from http import HTTPStatus
from http.server import BaseHTTPRequestHandler, ThreadingHTTPServer
from typing import Any
from urllib.parse import parse_qs, urlparse

logger = logging.getLogger(__name__)

DEFAULT_HOST = "0.0.0.0"
DEFAULT_PORT = 8787   # ← 도리당봇은 8788 사용


def _safe_json(data: Any) -> bytes:
    return json.dumps(data, ensure_ascii=False, indent=2).encode("utf-8")


class CombinedDashboardHandler(BaseHTTPRequestHandler):
    def log_message(self, fmt: str, *args: Any) -> None:
        logger.info("%s - %s", self.address_string(), fmt % args)

    def _send_json(self, payload: Any, *, status: int = 200) -> None:
        self._send_bytes(_safe_json(payload), content_type="application/json; charset=utf-8", status=status)

    def _send_bytes(self, payload: bytes, *, content_type: str, status: int = 200) -> None:
        self.send_response(status)
        self.send_header("Content-Type", content_type)
        self.send_header("Content-Length", str(len(payload)))
        self.end_headers()
        self.wfile.write(payload)


def run_server(*, host: str = DEFAULT_HOST, port: int = DEFAULT_PORT) -> None:
    logging.basicConfig(level=logging.INFO, format="%(asctime)s %(levelname)s %(name)s - %(message)s")
    server = ThreadingHTTPServer((host, port), CombinedDashboardHandler)
    logger.info("Starting server on http://%s:%s", host, port)
    try:
        server.serve_forever()
    except KeyboardInterrupt:
        logger.info("Server interrupted.")
    finally:
        server.server_close()


if __name__ == "__main__":
    run_server()
```

## Verification Loop

구현 완료 후 아래 루프를 **모든 Test Cases PASS까지** 반복한다.

```
LOOP until all PASS:
  1. Test Cases 1~14 순서대로 실행
  2. FAIL 항목 → 원인 분석
  3. 코드 수정
  4. 전체 Test Cases 재실행
종료 조건: 전체 PASS + Constraints 위반 없음
```

## Constraints

- **새 Ollama 클라이언트 작성 금지.** `qwen_client.get_ollama_client_with_candidates()` 재사용
- **FastAPI / Flask / uvicorn 도입 금지.** 리포에 없다. stdlib `ThreadingHTTPServer`만 사용
- **`FLOW_LEGACY_*` 상수 사용 금지.** 2026-08-03에 멈춘 stale 사본이다
- **파티션 읽기 후 `project_id`를 `astype(str)`로 정규화할 것.** 안 하면 int64/str 불일치로 조용히 0건
- **포트 8787 사용 금지** (기존 대시보드 점유). 8788 사용
- **경로 하드코딩 금지.** `paths.py` 상수만 사용
- **print 금지.** `logger` 사용
- **`gpt-oss`에 `format="json"` 전달 금지** (CUDA/stack-buffer 500 유발)
- **3개 프로젝트 외 데이터를 절대 반환하지 말 것** — tools 레벨에서 하드 필터
- **LLM이 tool 결과 없이 사실을 생성하지 못하게 할 것** — system prompt + tool 강제
- `chat.js`/`chat.css`는 2단계 크롬 확장에서 재사용하므로 서버 의존 하드코딩 금지
- 크롬 확장(2단계)은 **이번 범위 아님**
- 사내 공유 시 Windows 방화벽 인바운드 8788 허용이 별도로 필요하다 (코드 아님, 운영 안내)

## Do Not Ask — Decide Yourself

- 파일이 이미 존재하면: 덮어쓰기
- import가 모호하면: Reference Code의 패턴 따라가기
- 타입 힌트 여부: 기존 파일과 동일하게 (`from __future__ import annotations`)
- 주석 여부: 최소화 (WHY만, WHAT 설명 금지)
- 변수명·함수명 스타일: snake_case, 기존 파일과 동일하게
- UI 디자인 세부: 깔끔한 기본 스타일로 자체 결정, 한국어 UI
- SSE 이벤트 스키마: 자체 결정하되 `{"type": ...}` 구조 유지
